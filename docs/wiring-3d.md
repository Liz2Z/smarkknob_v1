# 工作台 3D 接线视图

在电机工作台侧栏选择「3D 接线」，或访问 `#wiring`。本机现有服务可用 `python3 admin/server.py` 启动，地址为 `http://127.0.0.1:8766/#wiring`。固件构建也会打包同一个模型和脚本；本次页面集成没有烧录硬件，已运行的旧固件不会自动出现新菜单。

拖动旋转、滚轮/双指缩放、Shift 拖动平移；键盘方向键平移，± 缩放，0 复位。支持立体、俯视、正面、背面和侧面，选择线路或金色端点可查看对应 GPIO。切换展开视图时重建模型与线路端点，电气身份保持不变。透明和标签开关用于查看被遮挡位置。

模型表示 C3、DRV8313/HW-974、2804 电机、配套 AS5600 和已选外部 12V 电源端。电源端只是连接符号，并非适配器外形。沿用 IN1/2/3→GPIO4/5/6、EN→7、nFT→10、SDA/SCL→20/21；不执行接口写入、启停、固件烧录或配置修改。

几何数据在 `admin/wiring/design.json`，UI 在 `section.html`/`viewer.css`，界面交互在 `viewer.js`，WebGL 场景在 `scene.js`。使用本地 Three.js r170 和 OrbitControls，许可证保留在 `vendor/LICENSE`。通过 `scripts/build_wiring.sh`（esbuild 0.25.5）打包为离线 IIFE，页面运行不请求 CDN；交互、阻尼或窗口变化时重绘。导线中心线严格沿 X/Y/Z 轴分段，转角 90°；每段独立圆柱，接点小球封口，不用曲线插值改变路线。模板通过 `WIRING_SECTION` 和 `WIRING_ASSETS` 标记组合；Python 与 Rust build.rs 共用资源，固件用静态 Flash 数据分段发送，不新增网络端点。

尺寸依据：卖家图给出电机外径34.5mm、本体15mm、含磁环座19.5mm；编码器包络33×33mm、PH2.0连接器。C3 的外形/排针坐标、DRV8313板外形/元件位置、编码器安装高度与接触点位置仍为估计。各模块分别记录尺寸和引脚置信说明。显示近似蝴蝶板、连接器、芯片、镀金孔与中空轴；板轮廓、安装槽、螺钉和 USB 插头细节不是精密实测模型。

当前布局让驱动板控制端面向 C3、电机三相出口面向驱动、编码器 P1 面向 C3，供电端靠近驱动电源入口。控制线集中走两层低位路径，编码器线束从电机侧面上升，nSP–nRT 在板边短接。旋转仅改变摆放，不改变模块局部引脚顺序、GPIO 或电气网络，也不表示实物已经重新接线。

装配视图折线总长从2054.75mm缩短到748.19mm，展开视图为848.19mm；nSP–nRT 跳线从约69.3mm缩短到8.54mm，每根电机相线小于25mm。两种布局均检查了正确旋转、网络连通、焊盘端点附着，最小不同网络表面净距均为0.550mm，模型线径0.7mm、要求净距0.4mm。额外检查线路避开驱动板电容的扩展包络；这不是完整元件碰撞验证，也不验证真实尺寸、绝缘、电流、气隙或安装公差。线长为当前视图折线之和，不含接头、弯曲半径和维修余量；展开图重新示意走线，不可据其直接裁线。

验证命令：

```sh
python3 admin/wiring/check_design.py admin/wiring/design.json
python3 -m unittest discover -s admin -p 'test_*.py'
node --test admin/test_embedded_panel.js
cargo clippy --offline --locked --release --bin motor-driver -- -D warnings
cargo build --offline --locked --release --bin motor-driver
```

`test_wiring.py` 也检查每条线段轴向和相邻折点的直角、展开布局、固定 GPIO/供电网络、短线束长度、端点引用、电容包络净距和页面离线打包。

2026-10-21 路由优化验证：7项接线回归测试通过，本机8766端口实际返回的页面包含最新模型。此前版本有浏览器交互验收记录；本轮浏览器绑定和截图接口持续超时，尚未完成新布局的网页目视验收。此次只修改接线示意数据及回归检查，没有调用控制接口、烧录固件或操作物理电机；设备内嵌页面需随后续固件更新才会采用新布局。
